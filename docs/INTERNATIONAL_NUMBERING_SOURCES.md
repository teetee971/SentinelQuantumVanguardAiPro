# Sources officielles de numérotation internationale

Statut : fondation testée. Ce catalogue ne constitue pas encore un annuaire mondial des opérateurs.

## Règle de preuve

Une source de numérotation peut décrire un plan national ou l'attribution d'un bloc. Elle ne prouve pas :

- l'identité de la personne qui appelle ;
- l'opérateur qui dessert actuellement le numéro après portabilité ;
- la légitimité de l'appel ;
- l'absence de spoofing.

L'interface affiche donc le type de couverture et renvoie vers la source officielle, sans inventer de résultat.

## Couverture initiale

| Pays | Autorité | Couverture publiée dans Sentinel |
|---|---|---|
| France | ARCEP | index local d'attribution de blocs |
| Autriche | RTR | source officielle de recherche et open data d'attributions |
| Royaume-Uni | Ofcom | source officielle de données de numérotation |
| Belgique | IBPT / BIPT | plan national référencé |
| Suisse | OFCOM / BAKOM | plan national référencé |
| États-Unis | NANPA | plan de numérotation référencé |
| Canada | CNAC | plan de numérotation référencé |
| Autres pays/territoires reconnus | UIT / ITU | répertoire des plans nationaux uniquement |

L'import automatique, la normalisation et l'actualisation des jeux de données hors France restent à construire pays par pays. Toute promotion vers « attribution de bloc » exigera un parseur, une date de fraîcheur, des tests et une vérification de licence.
