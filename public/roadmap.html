Roadmap

Feuille de route limitée aux capacités qui peuvent être distinguées du code actuel. Une fonctionnalité planifiée n'est pas une fonctionnalité livrée.

ACTUEL

Surface web / PWA

Maintenir la surface statique, la navigation, le manifeste PWA, le service worker et les validations de liens. Toute évolution doit rester compatible avec le périmètre réellement déployé.

ACTUEL

Gouvernance et sécurité

Conserver l'isolation Sentinel, les contrôles de supply chain, le fuzzing, CodeQL, les validations de gouvernance et les contrôles de contenu. Les contrôles doivent rester bloquants lorsqu'ils détectent une régression.

EN COURS DE VALIDATION

Android natif

Le code canonique est dans native-android-app/. Les builds et releases ne sont considérés comme validés qu'après exécution réelle et vérifiable du workflow correspondant. Aucun APK signé précompilé n'est promis ici.

FUTUR

Capacités EDR / agents

Les agents présentés dans l'interface restent conceptuels tant qu'une implémentation opérationnelle, ses contrôles de sécurité et ses tests ne sont pas présents et validés. Aucune activation autonome implicite.

FUTUR

Protection endpoint

Une éventuelle fonction antivirus ou EDR nécessiterait une architecture endpoint dédiée, des mécanismes d'isolation, des mises à jour contrôlées, des tests adversariaux et une validation de sécurité avant toute prétention opérationnelle.

RÈGLE DE RELEASE

Preuve avant affirmation

Pas de « production ready », de certification, de risque nul ou de validation complète sans preuve correspondant exactement à l'affirmation. Les échecs d'infrastructure GitHub restent distingués des échecs du code.
