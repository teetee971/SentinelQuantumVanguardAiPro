Configuration d'urgence

Utiliser les contrôles prévus dans config/feature-flags.js selon la procédure de déploiement validée.

Git

Revenir à un commit connu et validé avec une procédure de revue, puis redéployer via le pipeline de production.

Déploiement

Important.
Ne pas annoncer « rollback instantané », « risque zéro », « système stable » ou un statut de production sans preuve issue de l'environnement concerné.
