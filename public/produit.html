Local-first

Objectif d'architecture : des données qui restent sur vos appareils.

Le local-first est un objectif d'architecture, pas une capacité déjà opérationnelle de bout en bout. La version PC est pensée pour l'analyse locale, la conservation contrôlée des données, les rapports et les opérations qui demandent plus de ressources.

La version Android native agit comme compagnon de supervision : consultation, alertes, rapports de veille et coordination avec le poste principal lorsque la synchronisation chiffrée est prévue par la configuration.

Architecture

Séparation claire entre vitrine, licence et application.

Pas de cloud tiers pour le cœur local

La vitrine ne transforme pas le logiciel en service web gratuit. Les fonctions applicatives sont distribuées via les applications natives.

Base locale protégée

Le stockage local chiffré est présenté comme un objectif d'architecture pour les données sensibles manipulées par l'application installée.

Licence active

L'accès aux installateurs et aux modules payants passe par un espace client et une vérification de licence côté déploiement.

Preuves proportionnées

Les capacités restent documentées selon leur état réel : code présent, tests exécutés, artefacts générés et validations observées.
