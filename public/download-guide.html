Guide vitrine

Comment télécharger et installer le logiciel après activation de licence.

Cette page explique le parcours et documente le paquet Android signé préparé pour Play Console. L'AAB est un livrable éditeur : il se dépose dans Play Console, mais ne s'installe pas directement sur téléphone.

Accéder à la démonstration d'espace client
Accès réservé : les liens réels de téléchargement apparaissent uniquement dans l'Espace Client après vérification de la licence. La vitrine publique ne publie pas de fichier .exe, .msi ou .apk. Le paquet AAB éditeur ne contient aucune clé privée.
Android Play Console

Paquet AAB signé v1.0.0 prêt pour dépôt éditeur.

Le ZIP contient l'AAB signé, le certificat public d'upload et les checksums. Il ne contient pas le keystore, le mot de passe ni la sauvegarde de clé d'upload.

SentinelQuantumVanguard-PlayConsole-AAB.zip

À extraire, puis envoyer le fichier SentinelQuantumVanguard-v1.0.0-release-signed.aab dans Play Console.

SHA-256 ZIP : e1bfc5502b1b34746d8417939fb9f059e93e7222cf16f6491785214d3e98c5a5

Télécharger le ZIP AAB signé
  1. Télécharger le ZIP AAB signé depuis l'Espace Client.
  2. Extraire les 3 fichiers : .aab, SHA256SUMS.txt et upload_certificate.pem.
  3. Dans Play Console, créer ou ouvrir l'application Android puis envoyer le fichier .aab dans la piste de test ou de production choisie.
  4. Conserver séparément la sauvegarde de clé d'upload privée ; elle ne doit pas être publiée sur le site.
PC

Installation bureau locale.

  1. Choisir une offre et finaliser le paiement via le prestataire externe.
  2. Recevoir ou créer un compte avec une clé de licence.
  3. Ouvrir l'Espace Client et récupérer l'installateur signé présenté par le déploiement.
  4. Lancer l'assistant, initialiser la base locale chiffrée et saisir la licence.

Les formats attendus côté déploiement peuvent inclure .exe ou .msi, mais aucun fichier réel n'est exposé ici.

Android

Application native mobile.

  1. Ouvrir l'Espace Client depuis l'appareil ou suivre le canal mobile indiqué.
  2. Installer l'application Android native via le canal sécurisé prévu par le déploiement.
  3. Se connecter avec la même licence ou le compte associé.
  4. Activer, si disponible, la synchronisation chiffrée optionnelle avec le poste PC.

Le canal client peut être un magasin d'applications ou un fichier .apk réservé aux clients, selon les conditions de distribution. Pour tester sur téléphone avant publication Play Store, il faut un APK ; l'AAB signé sert à Play Console.

Utilisation

PC pour l'analyse, mobile pour le suivi.

Sur PC

Importer les données autorisées, lancer les analyses locales, consulter les tableaux de bord détaillés et générer les rapports.

Sur Android

Recevoir les notifications, consulter les synthèses, suivre la veille et vérifier l'état général en mobilité.

Parité adaptée

Le noyau fonctionnel reste commun, mais l'interface et les charges de travail sont adaptées aux capacités de chaque appareil.
