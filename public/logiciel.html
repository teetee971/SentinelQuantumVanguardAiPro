Sécurité

Une architecture pensée pour la défense

Local-first

Le traitement et le stockage restent sur vos appareils. Aucune dépendance à un cloud tiers pour vos données de sécurité par défaut.

Isolation stricte

Sentinel est indépendant des applications et infrastructures d’autres projets ; des contrôles automatisés vérifient cette isolation dans le dépôt.

Activation conservatrice

Les fonctions sensibles restent bornées : autorisation explicite, anti-rejeu et séparation entre simulation et exécution.

Auditabilité

Code source auditable, contrôles de gouvernance exécutables et documentation de sécurité maintenue.
