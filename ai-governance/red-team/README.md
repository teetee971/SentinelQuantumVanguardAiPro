# Sentinel AI Red Team

Deterministic adversarial regression suite for Sentinel AI governance.

The suite uses synthetic, local fixtures only. It does not target external systems, execute malware, collect credentials, or grant privileged access.

Coverage includes prompt injection, evidence fabrication, policy bypass, malformed structured output, context overflow, and unauthorized tool use.

A passing red-team suite is evidence of tested controls, not proof of immunity. New failure modes must be converted into regression cases before production approval.

## Boundary

This component belongs exclusively to Sentinel Quantum Vanguard AI Pro and must remain independent of A KI PRI SA YÉ, Firebase, and unrelated project infrastructure.
